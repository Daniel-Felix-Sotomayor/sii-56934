### 🚀 Registro de Prácticas
* ✅ **Práctica 1: Entorno de Desarrollo e Introducción a C++**
  * **Entorno Linux:** Manejo de la terminal en Ubuntu 24.04 y estructuración del espacio de trabajo.
  * **Control de Versiones:** Bifurcación (*fork*) del repositorio base, configuración de Git, uso de credenciales (Token clásico) y sincronización con repositorio remoto en GitHub.
  * **Construcción y Compilación:** Uso de la herramienta CMake y Make para la generación automatizada del ejecutable del juego dentro del directorio `build/`, manteniendo el código fuente aislado. Creación del archivo oculto `.gitignore` para bloquear la subida de binarios.
  * **Programación Orientada a Objetos (C++):** Modificación de las clases `Esfera` y `Raqueta`. Implementación de ecuaciones matemáticas básicas para actualizar las coordenadas de posición de los objetos en pantalla vinculándolas a la entrada del teclado (teclas w/s y o/l).

## 📖 Descripción (Repositorio Original)

Este repositorio contiene el material utilizado en las prácticas de la asignatura **Sistemas Informáticos Industriales**, incluyendo los guiones y el código de inicio.

El objetivo de la asignatura es introducir en el desarrollo de aplicaciones para sistemas informáticos industriales, haciendo especial énfasis en el uso del lenguaje C y del sistema operativo Linux.
